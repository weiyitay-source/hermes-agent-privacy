Privacy Policy

Last Updated: October 2026

1. Overview

Hermes Agent is a private, self-hosted tool used exclusively for personal productivity and automated task management.

2. Google User Data Handling

Hermes requests read-only access to Gmail via the https://www.googleapis.com/auth/gmail.readonly scope.

  • Data Collected: Email message headers, bodies, and timestamps necessary to parse personal alerts and workflows.
  • Data Storage: All retrieved email data is stored and processed locally on self-hosted infrastructure. No data is sent to external servers or third-party marketing services.
  • Data Sharing: No personal or email data is ever sold, transferred, or disclosed to third parties.
  • AI Model Training: Personal data retrieved via Google APIs is not used to train generalized AI foundation models.

3. Data Retention and Deletion

Tokens and processed data can be revoked and deleted at any time by clearing the local environment credentials or removing access via the Google Account Security settings.

4. Contact

For questions regarding this policy, contact the system administrator directly.
